# ARTAE USA — website

Static site for artaeusa.com (English, with a French toggle). Brand charter from artae.immo, used with Julien Calamote's approval.

- Pages: `index.html`, `services.html`, `academy.html`, `florida.html`, `about.html`, `contact.html`, `privacy.html`
- Styles: `css/site.css` · Script (language toggle, nav, cookie banner, form): `js/site.js` · Photos: `img/` (Unsplash, free licence)
- Hosted on GitHub Pages. Each push to `main` republishes the site.
- Texts are duplicated inline: `<span class="en">…</span><span class="fr">…</span>` (or `class="en"` / `class="fr"` on blocks).
